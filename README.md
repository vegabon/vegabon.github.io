# README

앱 지원 및 개인정보처리방침 페이지를 호스팅하는 GitHub Pages 사이트입니다.

## 페이지

### 우리집 달력 (MyHomeCalendar)

양력·음력·공휴일·24절기·기념일·손없는날·육십간지를 한 화면에서 보는 한국형 달력 iOS 앱

vegabon.github.io

- 지원 페이지: <https://vegabon.github.io/myhomecalendar/>
- 개인정보처리방침: <https://vegabon.github.io/myhomecalendar/privacy.html>

## 구조

앱마다 폴더 하나씩 사용합니다. 저장소 루트에 폴더를 추가하면 `https://vegabon.github.io/<폴더명>/` 경로로 자동 게시됩니다.
